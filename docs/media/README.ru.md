# Происхождение визуализаций

[English](README.md) | [Русский](README.ru.md)

GIF и PNG — **превью кода по разметке лексера**, не запись и не снимки интерфейса Notepad++. Стили и уровни сворачивания получены настоящей реализацией `fore::analyze`. Стандартные цвета взяты из поставляемых XML-пресетов. Для полного собственного примера стили/сворачивание визуализатора побайтно сопоставлены с нативным снимком Notepad++. [Отчёт](render-validation.json).

В превью тем используется [mcp-data-sources.fore](../../examples/third-party/mcp-data-sources.fore): строки 17–60 файла `fap_component/mod_mcp_server.fore` из [ForesightPlatform/fap_mcp_server](https://github.com/ForesightPlatform/fap_mcp_server/blob/cd6e589860225ee6201aadb603d4c586e5e5ea5d/fap_component/mod_mcp_server.fore#L17). Copyright (c) 2026 **Evgeny Bogdanov**, MIT. [Исходная лицензия](../../examples/third-party/LICENSE.fap_mcp_server.txt). Предоставленный локальный файл сверен с этой зафиксированной ревизией; выполнены только извлечение фрагмента и нормализация LF. [Хеши и источник](provenance.json).

Сворачивание показано на собственном `Fore-demo.fore`. Кадр со своими цветами показывает необязательные ручные значения: ключевые слова `#FFD166`, комментарии `#8BE28B`, строки `#FFA1B5`; это не третий автоматический пресет. Длительность кадра темы — три секунды, состояния сворачивания — 2,8 секунды. Вместо анимаций доступны статичные PNG. Английские и русские подписи создаются отдельно.

Изображения показывают лексическое оформление, а не подтверждают компиляцию примера в какой-либо версии платформы. Файлы шрифтов не включены. Другие предоставленные GitHub-примеры без установленной лицензии распространения не скопированы в публичный репозиторий.
