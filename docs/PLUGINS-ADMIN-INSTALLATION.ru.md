# Каталоговый пакет: Foresight Platform Fore

[English](PLUGINS-ADMIN-INSTALLATION.md) | [Русский](PLUGINS-ADMIN-INSTALLATION.ru.md)


Версия 1.1.0 для Windows x64 и x86. Выбирайте архив под архитектуру **Notepad++**, а не Windows. В каталоговом ZIP `ForeLexer.dll` находится в корне; Plugins Admin устанавливает его в `<Notepad++>/plugins/ForeLexer/`, документация находится в `plugins/ForeLexer/doc/` у проверенного WinGUp; руководство Notepad++ также описывает вариант `plugins/doc/ForeLexer/`.

Пока заявка не принята и обновлённый каталог не распространён, используйте ручной ZIP из [Releases](https://github.com/rhyots/notepad-plus-plus-syntax-plugin-foresight-platform-fore/releases). Публикация на GitHub сама по себе не добавляет плагин в Plugins Admin. См. [состояние заявки](PLUGINS-ADMIN-READINESS.ru.md).

После включения в каталог: откройте **Плагины → Управление плагинами → Доступные**, найдите **Foresight**, отметьте плагин и нажмите **Установить**. Сохраните работу перед перезапуском редактора. Новые версии появляются на вкладке **Обновления**; удаление — **Установленные → Удалить**. Архитектура пакета должна соответствовать редактору.

При первом запуске плагин создаёт `ForeLexer.xml` в каталоге конфигурации, который возвращает Notepad++, используя встроенную светлую палитру. Существующие настройки, включая общие файлы установки, сохраняются. Обновление сохраняет XML. После удаления могут остаться настройки , чтобы при повторной установке восстановить пользовательское оформление. Для их полного удаления закройте Notepad++, сохраните резервную копию и удалите только `ForeLexer.xml` этого плагина и, если он существует, отдельный каталог `plugins/doc/ForeLexer`. Документация внутри папки плагина удаляется вместе с ней.

Выберите **Синтаксисы → F → Fore**; оформление меняется в **Опции → Определение стилей → Fore**. Стандартные цвета следуют светлому/тёмному фону редактора в обоих представлениях и после перезапуска. Нестандартные цвета и шрифты сохраняются; смена темы не переписывает XML. Общая конфигурация установки имеет приоритет над профильной. См. [автоматические темы](AUTOMATIC-THEMES.ru.md).

Если старый UDL владеет `.fore`, удалите `fore` из его поля **Расш. / Ext.**. Плагин не изменяет определения UDL при запуске.

Автораспознавание ограничено обычным текстом в TXT, файлах без расширения и новых вкладках. Проверка выполняется после открытия/активации или редактирования, с задержкой 350 мс и пределом 128 КиБ. Нужны согласованные именованные блоки Fore; общих слов недостаточно. Строки и комментарии игнорируются; явный выбор языка, включая обычный текст, действует до закрытия документа. Меняется язык, но никогда текст. См. [подробности распознавания](AUTODETECTION.ru.md) и `examples/Fore-autodetect-demo.txt` в каталоге плагина.

Проверено: Notepad++ 8.9.8.1 x64 и x86. Правила языка: справка Prognoz Platform Fore 8.1. Поздние версии платформы отдельно не сертифицированы; Fore.NET и ARM64 вне этого выпуска. Четыре светлых цвета взяты со снимка платформы; [измерения и ограничения](PLATFORM-COLORS.ru.md).
