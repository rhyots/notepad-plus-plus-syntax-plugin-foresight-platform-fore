## Установка

Скачайте `*-x64.zip` для ручной установки из [Releases](https://github.com/rhyots/notepad-plus-plus-syntax-plugin-foresight-platform-fore/releases/latest). Нужен Notepad++ **Windows x64**; проверенная версия — 8.9.8.1. Сохраните работу, закройте редактор и полностью распакуйте архив.

В PowerShell 7 выполните `pwsh -File install.ps1 -NotepadDirectory 'C:\Program Files\Notepad++'` из распакованной папки. Для Program Files нужны права администратора. Для portable Notepad++ укажите папку его EXE. Скрипт проверяет архитектуру, сохраняет копии заменяемых файлов и удаляет из UDL только конкурирующее расширение `fore`. Копии и квитанции находятся в `ForeLexerBackups` каталога настроек.

`-Palette Dark` выбирает исходный тёмный XML. Обе палитры поддерживают автоматическое переключение тем. Для нестандартного профиля используйте `-ConfigurationDirectory 'C:\path\to\profile'`. [Подробности установщика](INSTALLATION.ru.md).

## Ручная установка

1. Закройте Notepad++.
2. Скопируйте `plugins\ForeLexer\ForeLexer.dll` из ZIP ручной установки в `plugins\ForeLexer\` рядом с установленным `notepad++.exe`.
3. Скопируйте `presets\ForeLexer-Light.xml` в `%APPDATA%\Notepad++\plugins\Config\ForeLexer.xml`. Для portable с локальными настройками используйте его собственный `plugins\Config\ForeLexer.xml`. При необходимости создайте каталоги. Можно выбрать тёмный пресет; имя целевого файла — обязательно **ForeLexer.xml**.
4. Перезапустите Notepad++ и откройте `.fore`. При необходимости выберите **Синтаксисы → F → Fore**.

XML в `plugins\Config\` каталога установки имеет приоритет над XML профиля. Оставьте одну нужную активную конфигурацию. Эти XML настраивают внешний лексер: импортировать их через «Задать свой язык» не нужно.

`*-plugins-admin-x64.zip` имеет другую структуру: DLL лежит в корне ZIP. Он подготовлен для каталога; плагин пока не включён в Plugins Admin.

## Открытие кода Fore

Связанное расширение — `.fore`. Другим файлам можно вручную назначить **Синтаксисы → F → Fore**. В строке состояния должен появиться Fore. Выбор языка не компилирует и не выполняет файл.

Если расширением владеет старый UDL Fore, откройте **Синтаксисы → Пользовательский синтаксис → Задать свой язык**, выберите этот UDL и удалите из поля расширений только `fore`. Установщик выполняет такую миграцию с резервной копией.

## Автораспознавание

Рассматриваются только документы **«Обычный текст»**: `.txt` без учёта регистра, файлы без расширения и новые несохранённые вкладки. Проверка выполняется после открытия/активации и через 350 мс после паузы редактирования; читаются не более первых 128 КиБ.

Распознаватель ищет согласованные именованные блоки Fore, пропуская комментарии и строки. Одних распространённых ключевых слов недостаточно. Другие расширения и уже выбранные языки сохраняются. Явный выбор языка, включая «Обычный текст», отключает распознавание для открытого документа до его закрытия. Закройте и откройте документ снова, чтобы разрешить распознавание.

Для проверки откройте [Fore-autodetect-demo.txt](../examples/Fore-autodetect-demo.txt) или вставьте весь его текст в новую безымянную вкладку обычного текста. Короткие или неполные фрагменты могут остаться обычным текстом. Ручной выбор Fore доступен всегда.

## Цвета и шрифты

Откройте **Опции → Конфигуратор стилей → Fore**, выберите категорию, измените цвет текста/шрифт/начертание и сохраните. Доступны 11 категорий, в том числе ключевые слова, типы, строки, обычные и документирующие комментарии.

Тему редактора выбирают в **Опции → Конфигуратор стилей → Выбрать стиль**. Плагин автоматически следует фактическому фону редактора в обоих представлениях, в том числе после перезапуска. Изменение только оформления окон приложения не обязательно меняет фон редактора.

Стандартные цвета управляются автоматически. Ручной цвет, отличающийся от обоих стандартных цветов своей категории, сохраняется; настройки шрифта тоже сохраняются. Выбор стандартного цвета возвращает категорию к автоматическому сопоставлению. Базовый XML в Конфигураторе может отличаться от адаптированных цветов документа; автоматическое переключение XML не переписывает.

Для показанного пользовательского тёмного оформления можно выбрать `#FFD166` для ключевых слов, `#8BE28B` для комментариев и `#FFA1B5` для строк на тёмном фоне. Это необязательные ручные настройки, а не дополнительный поставляемый пресет. [Статичное превью](media/custom.ru.png).

## Сворачивание

Сворачивайте блоки через поле слева от кода, рядом с номерами строк. Локальные объявления входят в область метода от его заголовка. У новых свойств есть общий блок и отдельные тела Get/Set; сигнатуры интерфейсов и делегаты не создают ложных блоков методов.

Поддерживаются классы, пространства имён, перечисления, условия, циклы, Select Case, Try и With. Отдельные ветви Case не сворачиваются. Окончания LF, CRLF и CR обрабатываются напрямую. [Примеры сворачивания](../examples/Folding-edge-cases.fore).

## Обновление и удаление

Перед обновлением сохраните работу и закройте редактор. Установщик создаёт новую резервную копию предыдущих DLL/XML. Он устанавливает выбранный пресет, поэтому сохраните копию прежнего XML, если хотите затем восстановить свои настройки. Само автоматическое переключение тем ручные настройки сохраняет.

Для ручного удаления закройте редактор и удалите его папку плагина `plugins\ForeLexer`. Отдельный файл настроек `ForeLexer.xml` можно оставить для будущей установки. Удаление плагина не восстанавливает прежнюю привязку UDL; при желании добавьте `fore` обратно вручную.

## Решение проблем

| Симптом | Что проверить |
|---|---|
| Нет Fore в группе F | Правильная DLL x64, путь `plugins\ForeLexer\ForeLexer.dll`, полный перезапуск |
| Ошибка XML или нет стилей Fore | Имя/положение `ForeLexer.xml`; отсутствие конфликта общей и пользовательской копий |
| `.fore` остаётся обычным текстом или UDL | Конкурирующее расширение UDL; затем выберите Fore вручную |
| TXT остаётся обычным текстом | Подходящее имя, полные именованные блоки в первых 128 КиБ, отсутствие ручного отключения для текущего документа |
| Цвета не меняются с темой | Фон редактора действительно изменился; нестандартные ручные цвета намеренно остаются прежними |
| Установщик не заменяет DLL | Все экземпляры этой установки Notepad++ закрыты; есть права записи в каталог установки |
| Код неверно выполняется в платформе | Плагин только подсвечивает/сворачивает; ошибки выполнения проверяются компилятором/отладчиком платформы |

В сообщении об ошибке укажите версии плагина и Notepad++, архитектуру Windows, тему, имя/расширение файла, окончания строк и минимальный фрагмент, которым можно поделиться. [Создать issue](https://github.com/rhyots/notepad-plus-plus-syntax-plugin-foresight-platform-fore/issues/new/choose).

## Что проверено

Notepad++ 8.9.8.1 x64 в Windows, обе палитры и оба представления, реальные смены тем, перезапуск, ручные настройки, правки текста, регистрация в меню/Конфигураторе/About, резервные копии установщика и LF/CRLF/CR. Правила языка взяты из справки Prognoz Platform Fore 8.1. Поздние версии платформы отдельно не сертифицированы; Fore.NET, x86 и ARM64 не являются поддерживаемыми целями. При проверке программы платформы не компилировались и не выполнялись.
