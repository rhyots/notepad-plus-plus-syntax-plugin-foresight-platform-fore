# Fore в Notepad++ — первый выпуск

Нативная подсветка, сворачивание и автоматические светлая/тёмная палитры для **Foresight Platform Fore / Prognoz Platform Fore**. Fore появляется в **Синтаксисы → F → Fore** и **Конфигуратор стилей → Fore**.

- 66 ключевых слов, 12 встроенных типов, 11 категорий стилей.
- Сворачивание методов вместе с объявлениями, классов, свойств, циклов и условий.
- Автораспознавание подходящего обычного текста: `.txt`, файлов без расширения и новых вкладок; ручной выбор языка имеет приоритет.
- Светлая/тёмная палитры следуют фону редактора; ручные цвета и шрифты сохраняются.
- Установщик с копиями и миграцией расширения `.fore` из старых UDL.
- Английская и русская документация, анимированные превью кода и реальный MIT-пример сообщества с указанием автора.

**Для ручной установки скачайте `NotepadPlusPlus-Syntax-Plugin-Foresight-Platform-Fore-1.0.0-x64.zip`.** Закройте Notepad++ и следуйте README из архива. `*-plugins-admin-x64.zip` предназначен для структуры каталога; плагин пока не включён в Plugins Admin. Отдельный `*-source.zip` содержит полное проверенное дерево исходников. Сверьте каждый ZIP с соответствующим `.sha256`.

Проверено: **Notepad++ 8.9.8.1 / Windows x64**. Правила: Prognoz Platform Fore 8.1. Поздние версии платформы отдельно не сертифицированы; Fore.NET/x86/ARM64 не являются целями. Компиляция и выполнение в платформе не проверялись. Локально пройдены 381 проверка нативной интеграции, 17 сценариев распознавания и 40 проверок тем. Статус CI и результаты — в репозитории.
