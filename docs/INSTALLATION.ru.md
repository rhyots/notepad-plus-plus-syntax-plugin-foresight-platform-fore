# Notepad++ Syntax Plugin for Foresight Platform Fore 1.0.0 — Windows x64

[English](INSTALLATION.md) | [Русский](INSTALLATION.ru.md)

Нативная подсветка Foresight Platform Fore и сворачивание блоков. Язык появляется в
**Синтаксисы → F → Fore**, цвета — в **Конфигураторе стилей → Fore**.

Проверено на **Notepad++ 8.9.8.1 x64**. Правила — по справке **Prognoz Platform Fore 8.1**.
Поддержка Fore.NET и других версий платформы отдельно не проверялась.
Проверено корректное сворачивание с LF и CRLF, а в ядре — также с CR.

## Установка

1. Распакуйте **весь** архив в обычную папку.
2. Сохраните файлы и закройте все окна Notepad++.
3. Для установки в `Program Files` откройте **PowerShell 7 от имени администратора**.
4. Перейдите в распакованную папку и выполните:

```powershell
pwsh -File install.ps1 -NotepadDirectory 'C:\Program Files\Notepad++'
```

Параметр `-Palette Dark` выбирает начальный базовый XML; стандартные цвета обеих палитр автоматически следуют за темой редактора.
Для portable-версии укажите папку её EXE. Для нестандартного профиля укажите
`-ConfigurationDirectory 'C:\path\to\profile'`.

Скрипт проверяет x64, сохраняет резервные копии, устанавливает DLL и XML.
Если UDL уже использует расширение `.fore`, скрипт снимает только эту ассоциацию;
сами UDL остаются доступны для ручного выбора. Резервные копии и журнал установки
находятся в `ForeLexerBackups` в папке конфигурации редактора.

Запустите Notepad++ и откройте файл `.fore`. В строке состояния должен появиться **Fore**.
Для ручного выбора используйте **Language → F → Fore**.

## Ручная установка

- `plugins/ForeLexer/ForeLexer.dll` → папка `plugins/ForeLexer/` установленного Notepad++.
- `presets/ForeLexer-Light.xml` или `presets/ForeLexer-Dark.xml` →
  `%APPDATA%\Notepad++\plugins\Config\ForeLexer.xml`.
- Для portable с `doLocalConf.xml` XML располагается в `plugins\Config` рядом с EXE.
- Уберите `fore` из поля **Ext.** прежнего UDL Foresight Platform Fore, если он установлен.

Внешний лексер ищет XML сначала в каталоге установки `plugins\Config`, затем в
пользовательском профиле. Не оставляйте две разные копии конфигурации, если хотите
редактировать цвета через обычный пользовательский профиль.
Через «Импорт пользовательского синтаксиса» этот XML устанавливать не нужно.

## Цвета

Откройте **Settings → Style Configurator → Fore**, выберите категорию, задайте цвет
и шрифт, сохраните. Светлая и тёмная палитры наследуют фон редактора;
используйте палитру, соответствующую его теме.

## Автораспознавание

Для языка «Обычный текст» проверяются `.txt`, файлы без расширения и новые вкладки. Согласованные именованные блоки Fore включают подсветку после открытия или вставки кода. Строки и комментарии пропускаются; другие языки и расширения сохраняются. Явный выбор обычного текста отключает распознавание до закрытия документа. Задержка — 350 мс, предел — первые 128 КиБ. Текст не изменяется. Подробности: `docs/AUTODETECTION.md` в бинарном ZIP; пример — `examples/Fore-autodetect-demo.txt`.

## Автоматическое переключение темы

Стандартные цвета Light/Dark автоматически выбираются по фону редактора, в обоих представлениях и после перезапуска. Нестандартные ручные цвета и настройки шрифтов сохраняются. Менять XML при каждом переключении темы не требуется. Подробности — в `docs/AUTOMATIC-THEMES.md` бинарного архива.
