# Draft Plugins Admin entry

`plugin-x64.draft.json` is generated by `python tools/package.py` from the final
Plugins Admin ZIP bytes. Its `id` hashes the entire ZIP, not the DLL or source tree.
`folder-name` remains `ForeLexer` to match `ForeLexer.dll`.

**Do not submit this draft yet.** Replace `OWNER` in the public homepage and
direct ZIP download URL after choosing the actual GitHub repository. The current
compatibility floor is the tested Notepad++ 8.9.8.1 x64, not an assertion that all
earlier ILexer5 editors were tested. Future versions still need testing.

After approval to publish: upload the exact ZIP, download it again, verify its
SHA-256 against `id`, run the official validator, test install/update/remove with
debug Notepad++ and WinGUp, then prepare a PR to `src/pl.x64.json` in the official
`notepad-plus-plus/nppPluginList` repository. No x86/ARM64 entries are prepared.

An entry in Plugins Admin does not make the plugin part of the Notepad++ core or
guarantee acceptance by maintainers. See [readiness report](../docs/PLUGINS-ADMIN-READINESS.md).
