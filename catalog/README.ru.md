# Записи Plugins Admin

[English](README.md) | [Русский](README.ru.md)


`plugin-x64.draft.json` и `plugin-x86.draft.json` создаются по окончательным байтам ZIP командами `python tools/package.py --architecture x64` и `--architecture x86`. Каждый `id` — хеш целого ZIP своей архитектуры. `folder-name` равен `ForeLexer`, как в `ForeLexer.dll`.

Домашняя страница и адреса файлов конкретной версии ведут в GitHub-репозиторий rhyots. Минимальная проверенная совместимость — Notepad++ 8.9.8.1 на обеих архитектурах, а не все предыдущие редакторы ILexer5. Запись ARM64 не отправляется.

Перед отправкой скачайте публичные файлы, сравните SHA-256 с `id`, запустите официальный валидатор и проверьте установку/обновление/удаление с официальными Debug Notepad++ и WinGUp. Две записи направляются в `src/pl.x64.json` и `src/pl.x86.json` репозитория `notepad-plus-plus/nppPluginList`. [Готовность, результаты и ограничения](../docs/PLUGINS-ADMIN-READINESS.ru.md).

Байты опубликованных выпусков неизменяемы; изменённому ZIP нужны новый выпуск и хеш. Принятие в каталог не делает плагин частью ядра Notepad++. Сопровождающие решают, включать ли его и когда.
