# Участие в разработке

[English](CONTRIBUTING.md) | [Русский](CONTRIBUTING.ru.md)

Приветствуются сообщения об ошибках, примеры синтаксиса Fore и улучшения документации. Приложите небольшой воспроизводимый пример, версии плагина/Notepad++, архитектуру Windows, тему и окончания строк. Укажите, относится ли проблема к подсветке, сворачиванию, распознаванию или цветам. Публикуйте только код, которым имеете право делиться.

Правила языка должны опираться на исходную документацию Прогноз/Foresight. Различайте Fore и Fore.NET, отмечайте особенности версий. При изменении логики лексера добавляйте проверки поведения; открытие кода в Notepad++ не является проверкой его выполнения в платформе.

Поддерживайте равнозначность английских и русских README и руководств. Сохраняйте точные байты зафиксированных исходников, SDK и примеров. См. [сборку и проверку](docs/RELEASING.ru.md). Работайте в ветке, а в pull request опишите проблему, новое поведение и выполненные проверки.

Собственные изменения проекта распространяются под [MIT License](LICENSE). Сохраняйте авторство и лицензии сторонних компонентов. Перед крупной новой возможностью создайте issue для обсуждения.
