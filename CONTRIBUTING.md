# Contributing

[English](CONTRIBUTING.md) | [Русский](CONTRIBUTING.ru.md)

Bug reports, Fore syntax examples and documentation improvements are welcome. Include a small reproducible example, plugin/Notepad++ versions, Windows architecture, theme and line endings. Say whether the issue concerns highlighting, folding, detection or colors. Share only code you are allowed to publish.

Language rules should be grounded in original Prognoz/Foresight documentation. Distinguish Fore from Fore.NET and document build-specific differences. Add behavior-focused regression coverage when changing lexer logic; do not claim platform execution was tested by merely opening code in Notepad++.

Keep English and Russian READMEs and user guides equivalent. Preserve exact bytes in locked source/vendor/fixture files. See [build and validation steps](docs/RELEASING.md). Use a branch and describe the problem, resulting behavior and checks in the pull request.

Original project contributions are under the [MIT License](LICENSE). Preserve third-party attribution and licenses. Please open an issue before a substantial new feature.
